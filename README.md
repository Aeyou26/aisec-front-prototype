# CNNS-template

这是一个使用 Vite、Vue3、TypeScript、Arco Design 等技术栈搭建的项目模板，同时也包含了 ESLint、Prettier、Stylelint 等代码规范工具配置。

## 特性

- 基于 Vue3 和 Vite 构建，提供快速开发和构建能力
- 使用 TypeScript 进行类型检查和编译
- 集成 Arco Design UI 组件库，提供美观的样式和丰富的组件
- 配置了常用的代码规范工具，如 ESLint、Prettier、Stylelint、husky
- 集成了 Pinia 状态管理库，方便管理应用状态
- 集成了 axios 库，简化了客户端 HTTP 请求
- 集成了 vueuse 工具库，提供许多实用的 Vue 逻辑函数和组合式 API
- 集成了 mitt 事件处理库，方便数据传输与组件通信
- 集成了 Vue Router 路由库，方便进行页面路由操作
- 集成了 husky 工具，方便进行 Git 钩子操作
- 集成了 uno CSS 工具库，提供强大的 CSS 类型系统和自定义主题功能
- 项目提交时会自动对代码进行风格格式化

## 安装

在终端中执行以下命令来安装依赖：

```
npm install
```

## 快速开始

在终端中执行以下命令启动本地开发服务器：

```
$ npm run dev
```
